# diplom_proekt

Фроггер - лента постов, где дата публикации поста не влияет на то, когда вы его увидите. Вскопайте прошлое или подумайте о настоящем - посмотрите фото 80ых, узнайте о культуре 00ых или обсудите самое новое видео бумаги А4. Сравните ваше мнение с мнением людей прошлого года с помощью инновационных реюзабельных опросников!
